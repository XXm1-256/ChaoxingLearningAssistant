# 学习通课程播放辅助 v1.32

[下载可直接使用的 Windows 便携版](../../releases/latest) · [打开图文教学](使用教学.html) · [查看构建说明](BUILD.md)

Windows 10/11 桌面辅助工具。它只在学习通真实页面中读取课程、章节、视频任务和播放器状态，并辅助真实导航、播放、暂停、倍速继承、会话恢复与统计；不伪造观看时长或完成状态，不自动答题、考试、签到，也不绕过验证码、人脸、学校 SSO 或风控。

## 作品介绍

本作品面向希望减少重复点击、清楚查看当前章节和视频顺序的同学。程序持续开启时，会优先播放同章节后续真实视频，跳过测验、作业等非视频任务，再寻找后续尚未完成的视频章节。按压反馈、状态提示和内置教学用于说明操作是否生效。

本作品只是辅助工具，与超星学习通官方不存在隶属、授权或合作关系。使用前请遵守学校、课程与平台规则；程序不保证平台最终记录结果，重要课程请人工核对实际进度。完整边界见 [使用教学](使用教学.md) 与 [已知限制](KNOWN_LIMITATIONS.md)。

## v1.32 本轮重点

新增适合 GitHub 公开发布的源码结构、MIT 许可证、贡献与安全说明；普通下载包采用“外层图文教学 + 次级程序文件夹”，避免打开压缩包后直接面对大量文件。程序功能包括操作反馈、四步教学、同章视频优先和整课顺序播放。详见 `RELEASE_v1.32.md` 与 `PRODUCT_EXPECTATIONS.md`。

## 继承自 v1.24 的能力

- 播放统计只累计实际观察到的播放区间，不再把暂停或电脑休眠时间算入。
- 手动换视频、网页自动换视频或切换页面时，上一条统计会先独立结算，避免记录串片。
- CDN 临时签名变化不再被误判成换视频；旧的 ended 播放器也用强媒体证据判断。
- 诊断包保存最近一次完整播放器快照，不再只有倍速。
- 最近一次有效课程列表会写入 30 天缓存；短暂扫描失败不会清空左侧课程。
- 设置文件在启动和保存时自动归一化；JSON 写入保留上一份有效备份。

## 使用

普通使用者请从 GitHub Releases 下载 `ChaoxingLearningAssistant_v1.32_Windows.zip`，完整解压后先打开最外层 `使用教学.html`，再进入次级文件夹双击程序。源码构建可运行 `START.bat` 或 `BUILD_V1_32.bat`。

发布物严格分成两份：GitHub 用户版 ZIP 不含开发归档；开发者版 `ChaoxingLearningAssistant_v1.32_Developer.zip` 包含完整源码、累计 MASTER、错误档案、测试报告和各版本 Release 记录。开发者版不作为普通用户下载资产上传。

累计式、自包含归档：`ChaoxingLearningAssistant_MASTER_v1.32.txt`。

本版已在 Windows 完成编译和自动化测试；真实学习通课程仍需账号环境验收，详见 `KNOWN_LIMITATIONS.md`。
