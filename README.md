# 学习通课程视频播放助手 v1.41

[查看 Windows 便携版下载区](../../releases) · [阅读使用教学](使用教学.md) · [查看常见问题](常见问题与处理方法.md) · [查看构建说明](BUILD.md)

Windows 10/11 桌面辅助工具。它只在学习通真实页面中读取课程、章节、视频任务和播放器状态，并辅助真实导航、播放、暂停、倍速继承、会话恢复与统计；不伪造观看时长或完成状态，不自动答题、考试、签到，也不绕过验证码、人脸、学校 SSO 或风控。

## 作品介绍

本作品面向希望减少重复点击、清楚查看当前章节和视频顺序的同学。程序持续开启时，会优先播放同章节后续真实视频，跳过测验、作业等非视频任务，再寻找后续尚未完成的视频章节。按压反馈、状态提示和内置教学用于说明操作是否生效。

本作品只是辅助工具，与超星学习通官方不存在隶属、授权或合作关系。使用前请遵守学校、课程与平台规则；程序不保证平台最终记录结果，重要课程请人工核对实际进度。完整边界见 [使用教学](使用教学.md) 与 [已知限制](KNOWN_LIMITATIONS.md)。

## v1.41 本轮重点

- 刚进入课程、尚未手动打开任何章节时，“开始”和“打开未完成章节”会自动打开首个真实章节，让学习通生成完整目录后继续查找。
- 自动初始化会排除“返回课程”、章节测验、作业、签到和考试，不把非视频操作当作章节入口。
- 每次查找会连续三次核对整份章节与视频状态；中途状态变化便重新计数，避免第一次选错、反复点击后才逐渐正确。

## v1.39 重点

- 当前章最后一个视频播放时，后续章节即使尚未提前暴露视频类型，只要平台明确标为未完成，也会进入待核验队列。
- 播放中先预告并锁定下一未完成章节；当前视频结束并进入目标章节后，再识别其中第一条真实未完成视频。
- 目标章节实际只剩测验、作业或已完成视频时，仍会复核并继续向后寻找，不把章节总状态当成视频状态。

## v1.38 重点

- 左侧课程改为单击进入，并自动切换到章节页签显示读取状态。
- 普通课程首页也会主动读取章节目录，不再要求先手动打开某个章节。
- 页面异步生成章节目录或目录 iframe 较慢时，会先短暂重试，之后继续后台补读。
- 章节目录加载成功后，“打开未完成章节”再按真实视频状态寻找目标，避免空目录误报。

## v1.34 重点

修复课程栏把“返回课程”附近的“提示”误当成课程；进入学习页后显示真实课程卡；播放过程中持续预告下一视频，同章节多视频优先且跳过测验等非视频任务。章节仅因测验未完成、但其中视频已全部完成时，不再被当成待播目标。F11 可让学习通网页铺满窗口。

## 继承自 v1.24 的能力

- 播放统计只累计实际观察到的播放区间，不再把暂停或电脑休眠时间算入。
- 手动换视频、网页自动换视频或切换页面时，上一条统计会先独立结算，避免记录串片。
- CDN 临时签名变化不再被误判成换视频；旧的 ended 播放器也用强媒体证据判断。
- 反馈包保存最近一次完整播放器快照与程序日志，便于定位问题。
- 最近一次有效课程列表会写入 30 天缓存；短暂扫描失败不会清空左侧课程。
- 设置文件在启动和保存时自动归一化；JSON 写入保留上一份有效备份。

## 使用

普通使用者请在 GitHub Releases 页面确认版本标记为 v1.41 后，下载 `ChaoxingLearningAssistant_v1.41_Windows.zip`。完整解压后先打开最外层教学或常见问题文档，再进入“学习通课程视频播放助手”次级文件夹双击程序。源码构建可运行 `START.bat` 或 `BUILD_V1_41.bat`。

本版已在 Windows 完成编译和自动化测试；真实学习通课程仍需账号环境验收，详见 `KNOWN_LIMITATIONS.md`。
